BIGTECHOTEST (BTT) — ДИАГНОСТИКА ПК / НОУТБУКА  v1.3
================================

КАК ЗАПУСТИТЬ
  Дважды кликнуть PC-Diagnostika.exe (или PC-Diagnostika.cmd — это одно и то же) -> согласиться на права
  администратора -> ответить на вопросы. Рядом должна лежать папка tools (иначе программа скачает её сама).
  Если Windows покажет «Windows защитила ваш компьютер» -> «Подробнее» -> «Выполнить в любом случае».

РЕЖИМЫ (выбираются в окне при запуске)
  Только выбранные тесты — галочками отметьте нужное (например, только видеокарту или только диск)
      и задайте длительность стресс-тестов; окно сразу показывает примерное время.
      В отчёт попадут общие сведения о компьютере и выбранные проверки.
  Быстрая (~40 мин): вся информация, стресс CPU 90 с + Prime95 3 мин + y-cruncher 2 мин, GPU 60 с,
      тест диска и памяти, быстрая проверка на вирусы.
  Полная (~2 ч): стресс CPU 5 мин + Prime95 10 мин + y-cruncher 10 мин, FurMark 5 мин, большой тест памяти,
      WinSAT, проверка системных файлов (DISM, SFC) и диска (CHKDSK).

ЧТО ДЕЛАЕТ
  • Система, BIOS, материнская плата, Secure Boot, TPM, Windows, активация, антивирус, брандмауэр
  • Процессор: 7-Zip benchmark, собственный тест, стресс-тест и Prime95 с контролем температуры/частоты/
      троттлинга и итоговым ВЕРДИКТОМ ПО ОХЛАЖДЕНИЮ (норма / пора менять термопасту / перегрев)
  • y-cruncher: бенчмарк «π до 1 млрд знаков» (сравним с hwbot.org) и стресс-тест процессора+памяти —
      ловит нестабильный разгон и XMP/EXPO
  • Память: модули, слоты, частоты, тест на ошибки
  • Видеокарта: драйвер, видеопамять, FurMark (баллы, FPS, температура, потребление), мониторы
  • Диски: полный SMART (переназначенные/нестабильные сектора, ошибки, аварийные отключения, наработка,
      сколько записано), износ SSD, температура, скорость (DiskSpd: последовательная и 4К), свободное место
  • Аккумулятор (ноутбук): износ, циклы, работает ли зарядка (блок питания, ограничение заряда)
  • Все устройства и драйверы, ошибки Диспетчера устройств
  • Программы: полный список, автозагрузка, нежелательный софт, программы удалённого доступа
  • Журналы: синие экраны, аппаратные ошибки WHEA, ошибки дисков; разбор каждого внезапного выключения:
      пропало питание / завис и выключили кнопкой / синий экран / сбой сна
  • Проверка на вирусы: обновление баз и быстрое сканирование Microsoft Defender
  • Сеть: адаптеры, Wi-Fi (сигнал, стандарт, диапазон), пинг, DNS, скорость интернета
  • С вашим участием: клавиатура (все клавиши), мышь, тачпад, битые пиксели, динамики L/R, микрофон, камера
  • Драйверы: установка недостающих и обновление (Windows Update + Snappy Driver Installer), точка восстановления

РЕЗУЛЬТАТ
  На Рабочем столе два файла:
    Итог_диагностики_… — короткая понятная страница для клиента (оценка, что проверено, что сделать),
        кнопка «Сохранить в PDF»;
    Диагностика_… — полный отчёт: оценка 0–100, проблемы с советами, бенчмарки, все подробности.
  Копии — в папке reports.
  Копия отчёта автоматически отправляется в сервис для статистики (только сведения о технике и проверках).
  Нет интернета — отчёт ляжет в reports\unsent и уйдёт при следующем запуске.
  Если интернет есть, в отчёте появится сравнение с другими компьютерами из базы (процессор, видеокарта,
  диск, память) — и предупреждение, если результат заметно ниже, чем у таких же моделей.

ВАЖНО
  • Программа обновляется сама: при запуске проверяет новую версию (с проверкой контрольной суммы).
  • Папку v1 целиком (вместе с tools) можно носить на флешке и запускать на любых ПК — интернет нужен только
    для обновления драйверов и теста скорости. Если папки tools нет, программа скачает инструменты сама
    (с проверкой контрольных сумм).
  • Температура процессора: Windows без драйвера её не отдаёт. Программа предложит поставить открытый драйвер
    датчиков PawnIO на время теста и после теста удалит его.
  • Snappy Driver Installer качает драйверы торрентом — бывает медленно; в быстром режиме запускается только если есть устройства без драйверов
    (лимит 25 мин), в полном — всегда (лимит 45 мин).
    Скачанное сохраняется в tools\SDIO, следующие запуски быстрее.
  • Обновление BIOS автоматически НЕ выполняется (риск «окирпичить» плату) — только если вы явно согласитесь
    и Windows Update сам предложит официальную прошивку. Ссылка на сайт производителя — в отчёте.
  • Во время FurMark и стресс-тестов компьютер шумит и греется — это нормально. Тесты останавливаются сами
    при 95 °C на видеокарте и 100 °C на процессоре.
