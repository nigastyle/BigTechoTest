# BigTechoTest — исходники

Диагностика ПК и ноутбуков (Big Techno Club). Приватный репозиторий исходного кода.
Готовая программа и автообновления — в публичном репозитории **[BigTechoTest-releases](https://github.com/nigastyle/BigTechoTest-releases/releases/latest)**.

## Что где

| Путь | Что это |
|---|---|
| `pcdiag/body.ps1` | основной сценарий программы (PowerShell 5.1) |
| `pcdiag/modules/` | проверки-модули, вставляются в `body.ps1` при сборке (`lib-` библиотеки, `hw-` железо, `logs-` журналы, `stress-` нагрузочные тесты, `final-` итоги); правила — `modules/README-API.md` |
| `pcdiag/core.cs`, `pcdiag/ui.cs` | встроенный C#: тесты и окна программы |
| `pcdiag/ext/BTT-Drivers.ps1` | автоустановка драйверов (отдельный файл выпуска) |
| `exe/` | запускатель `BigTechoTest.exe` (.NET Framework 4.8) |
| `pcdiag/build.sh`, `exe/build-exe.sh` | сборка `.cmd` и `.exe` |
| `test.sh` | **тестовая** сборка → папка «Тест» на рабочем ПК (на GitHub не попадает, сама не обновляется) |
| `release.sh` | **выпуск** стабильной версии: подпись RSA-3072 → GitHub Release → папка «Стабильная» |
| `btt-update-pub.pem` | открытый ключ проверки подписи обновлений (закрытый — только на сервере выпуска) |

## Порядок работы

1. Все изменения — в рабочей копии, проверка тестовой сборкой: `./test.sh`
2. Когда всё стабильно: `./release.sh 1.6 "что нового"`
3. Программа у пользователей сама обновляется с GitHub (подпись манифеста обязательна).

Результаты диагностик хранятся на сервере статистики, не в Git.
